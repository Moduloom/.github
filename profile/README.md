# Moduloom

在一个 Web 工作台里预览组件、切换主题、调整参数并导出配置。

[![Moduloom 组件预览工作台](https://raw.githubusercontent.com/Moduloom/moduloom/main/docs/preview.png)](https://github.com/Moduloom/moduloom)

| 项目 | 用途 |
| --- | --- |
| [Moduloom](https://github.com/Moduloom/moduloom) | 基于 React 和 Vite 的组件预览工作台 |
| [Loom UI](https://github.com/Moduloom/loom-ui) | 提供表单、弹窗、菜单和布局的 React 组件库 |
| [BetterGI UI](https://github.com/Moduloom/bettergi-web-ui) | 以 BetterGI 原版 WPF 为参考的 Web 组件和页面预览 |

源码采用 GPL v3。启动命令和预览图见各仓库的 README。
