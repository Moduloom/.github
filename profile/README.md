# Moduloom

我们维护 React 组件库的浏览器工作台和两套 UI 实现。

[![Moduloom 的组件场景与参数面板](https://raw.githubusercontent.com/Moduloom/moduloom/main/docs/preview.png)](https://github.com/Moduloom/moduloom)

## 项目

| 项目 | 用途 |
| --- | --- |
| [Moduloom](https://github.com/Moduloom/moduloom) | 在浏览器里预览组件、调整参数和对照主题 |
| [Loom UI](https://github.com/Moduloom/loom-ui) | React 基础组件和主题 Token |
| [BetterGI Web UI](https://github.com/Moduloom/bettergi-web-ui) | BetterGI 的组件和应用界面预览 |

三个项目的源码均使用 GPL v3。各仓库的 README 有运行示例。
